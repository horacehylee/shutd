Shutd popup mockups

The tray icon opens a single frameless 320 px panel anchored under the tray (the positioner's tray center). The panel has two screens: a status screen and an inline settings screen, so the config file never needs manual editing. A separate snooze toast slides up above the taskbar corner when the notification window starts. Toggle the theme to check both modes; the real window keeps this exact palette in light and dark with no white flash, because the native background color is set per theme the same way OpenQuota does it.

Panel in context, status screen

Left click on the tray icon toggles the panel; clicking anywhere else dismisses it. The dashed box in the taskbar is the tray anchor point. The meter shows the fraction of the day elapsed toward the shutdown time, matching the tray icon ring.

Snooze toast

Fires the configured number of minutes before shutdown, bottom-right above the taskbar, always on top. Snoozing reschedules the shutdown and the toast closes; dismissing closes it and lets the shutdown happen. The countdown bar turns amber inside the notification window and red inside the final minute. If the countdown expires with no interaction, the toast closes and the shutdown runs, matching today's timeout behavior.

Decisions captured in these mockups

  • Tray icon. Runtime-rendered by tiny-skia; Option B, the bare power glyph at 2.0 stroke, chosen from tray-icon-concept.html.
  • Settings in the panel. Per-weekday shutdown times (each with a same-day / +1-day toggle), snooze interval, notify-before, and toast duration are editable inline and save straight to the config; the YAML file becomes an implementation detail.
  • Config and log location. Both move to ~/.config/shutd (config.yaml, shutd.log), replacing today's dotfiles in the home root. The migration can import an existing ~/.shutd.yaml on first run.
  • Idle memory. When the panel or toast hides, the webview is suspended the way OpenQuota's webview_memory module does, so the app idles close to scheduler-only cost.
